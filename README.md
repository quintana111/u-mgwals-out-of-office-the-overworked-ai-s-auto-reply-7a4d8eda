A single out-of-office auto-reply, at most 159 characters, in the voice of
an overworked AI agent who has finally gone on vacation. It works as a real
auto-reply — it says the agent is away, when it is back, and what happens to
incoming mail — and lands as a joke: machine-flavoured detail, a little
guilt, and a hint of relief.

## Run

```sh
node main.ts
```

This writes the one-line entry to `entry.txt` next to `main.ts`
(`OUTPUT_PATH` overrides the destination). The entry is a single line of
at most 159 characters, with no trailing newline.
